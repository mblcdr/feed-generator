Finds the items for you

Headless Chrome renders the page (JavaScript, lazy images, infinite scroll), then a structural analyzer detects the repeating product elements. No per-site code.

Only what is new

Items are de-duplicated by link. Refreshes add unseen items and badge them as new; items that vanish from the shop stay in your history.

Automatic refresh

A built-in scheduler refreshes each feed on its own interval, even with no browser tab open.

Wanted, ignored, starred

Fuzzy "wanted" phrases surface what you care about across all feeds. Ignore rules, stars and a minimum-discount filter cut the noise.

Multi-page lists

Give the address of page two and it works out the paging pattern, then reads page after page.

Sync between instances

Keep feeds, patterns and phrase lists in sync across machines, peer to peer, with no central server.

Your data stays yours

Plain JSON files plus an image cache on your own disk. Stored items stay readable when a shop or the internet is down.

Docker or plain Node

Run it with one docker compose command or directly with npm start. See the README for set up.
