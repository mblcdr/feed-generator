Turn any store page into your own feed

Paste the address of a category or search results page. Feed Generator finds the products, stores them, and shows you what is new on every refresh. Self-hosted, no accounts, no cloud.

Highlights

A small Node.js app with a clean browser UI. No framework, no database.

🔎

Finds the items for you

Real headless Chrome renders the page (JavaScript, lazy images, infinite scroll), then a structural analyzer detects the repeating product elements. No per-site code.

🆕

Only what is new

Items are de-duplicated by link. Refreshes add unseen items and badge them as new. Items that vanish from the shop stay in your history.

⏱️

Automatic refresh

A built-in scheduler refreshes each feed on its own interval (from every minute to every 30 days), even with no browser tab open.

⭐

Wanted, ignored, starred

Fuzzy "wanted" phrases surface what you care about across all feeds. Ignore rules (phrases or regex), stars and a minimum-discount filter cut the noise.

📄

Multi-page lists

Give the address of page two and it works out the paging pattern, then reads page after page with a backfill of older items.

🔄

Sync between instances

Keep feeds, patterns and phrase lists in sync across several machines, peer to peer, with no central server.

💾

Your data stays yours

Everything is plain JSON files plus an image cache on your own disk. Stored items stay readable when a shop or the internet is down.

🌗

Responsive, light and dark

A dependency-free vanilla JS interface that works on desktop and phone, and follows your system theme.

🐳

Docker or plain Node

Run it with one docker compose command (Intel and ARM images) or directly with npm start using your own Chrome, Chromium, Edge or Brave.

How it works

Four steps from a URL to a feed.

  1. Add a feedEnter the address of a listing page, a name, and optionally the expected number of items or the address of page two.
  2. Confirm the itemsIf the analyzer is confident the feed is created straight away. Otherwise pick one of up to 8 candidates, or paste the HTML of one example item.
  3. BrowseScroll a clean list with image, title, price, old price and delivery info. Click an item to open the original product page.
  4. Stay updatedHit Update or let the scheduler do it. New items appear first, marked as new.

Set up

Pick Docker for the least effort, or run it directly with Node.js 20 or newer.

No login. The app has no authentication and listens on your local network by default. Use it only on networks you trust and never expose its port to the internet. Restrict it to this computer with BIND_ADDR=127.0.0.1 (Docker) or HOST=127.0.0.1 (Node).

🐳 With Docker

Needs Docker with Compose. The image bundles Chromium.

git clone https://github.com/__REPO__.git
cd __NAME__
docker compose up -d --build

Open http://localhost:5959. Your data lives in the feed-data volume and survives updates.

Or skip the build and use the prebuilt image:

FEED_IMAGE=ghcr.io/__REPO_LC__:latest \
  docker compose -f compose.ghcr.yaml up -d

Options go in a .env file: HOST_PORT, BIND_ADDR, FEED_LANG, TZ, ALLOWED_HOSTS.

💻 Without Docker

Needs Node.js 20+ and a Chromium-based browser (Chrome, Chromium, Edge or Brave), or let the app download one.

git clone https://github.com/__REPO__.git
cd __NAME__
npm install
npm run setup   # optional: downloads Chrome for Testing
npm start

Open http://localhost:3000. Data is stored in ./data.

Use a specific browser with CHROME_PATH="/path/to/browser" npm start. Add HEADFUL=1 to watch it work.

Pin a Docker version

Releases are published as version tags, so you decide when to upgrade.

TagMeaning
latestThe newest build of the main branch. Convenient, but it can change at any time.
1.2.0Exactly this release. Never changes. Best for stability.
1.2The newest 1.2.x patch release. Gets bug fixes only.
sha-abc1234A specific commit, for testing or rollbacks.
FEED_IMAGE=ghcr.io/__REPO_LC__:1.2.0 \
  docker compose -f compose.ghcr.yaml up -d

To upgrade, change the tag and run the same command again. Your data volume is kept. See the releases for what changed.

Use it responsibly

Many sites forbid automated access in their Terms of Service or robots.txt. Feed Generator is meant for personal, low-volume use. Check the terms of every site you add, keep refresh intervals reasonable, and do not use it to bypass access controls or redistribute scraped content. You are responsible for how you use it.
